# Site Entendendo o Jogo

Site estático de www.entendendoojogo.com.br, publicado pela Vercel.

- Cada página fica em `<endereço>/index.html` (ex.: `cursos/jogo-de-posicao/index.html`).
- `assets/`: imagens, vídeos e PDFs.
- `eoj-runtime.js`: script leve que monta as partes interativas (filtros, contadores, formulários, menu do celular).
- `site.css`: ajustes comuns, incluindo a versão para celular.
- `vercel.json`: endereços limpos e redirecionamentos dos endereços antigos.
